# 새싹 LMS (Learning Management System) - Frontend

## 프로젝트 소개
새싹 LMS의 프론트엔드 프로젝트입니다. React를 기반으로 한 학습관리시스템의 사용자 인터페이스를 제공합니다.

## 팀원
- **팀장**: 신동진 (프로젝트 관리 및 사용자 CRUD)
- **팀원**: 성기범 (결제 CRUD)
- **팀원**: 정진욱 (강좌 CRUD)
- **팀원**: 홍인표 (강의 CRUD)

## 기술 스택
- React 18
- React Router DOM (라우팅)
- Tailwind CSS (스타일링)
- AWS SDK
  - S3
  - Cognito
- Axios (HTTP 클라이언트)
- HLS.js (비디오 스트리밍)

### 필수 요구사항
- Node.js 20.x 이상
- npm 또는 yarn

## 주요 기능
- 사용자 인증 (로그인/회원가입)
- 강좌 관리
  - 강좌 목록 조회
  - 강좌 생성 및 수정
  - 강의 콘텐츠 업로드
- 강사 대시보드
  - 통계 및 수익 현황
- 비디오 스트리밍
- 결제 시스템 연동

## 배포
- AWS S3 및 CloudFront를 통한 호스팅
